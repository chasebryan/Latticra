Dry-run blocks writes. Guarded local only arms user-local write simulation in this isolated test lane.

Primary actions update the isolated test UI lane only and do not mutate the guarded Panel implementation.

Accepted install prefixes must stay user-local. Remote, root, and system prefixes are blocked.

Receipt preview is a no-effect JSON summary of current test-lane state and recent operator events.

Receipt schema map rows expose the current value, source UI surface, and release status for each field. Blocked fields are intentional production gates.

Receipt checklist changes update only the isolated no-effect receipt preview. Guarded items require local mode and an accepted user-local prefix before they can be recorded.

Saved receipts are local no-effect snapshots. Selecting a saved receipt compares its event, checklist, schema, mode, and prefix state against the current preview.

Saved receipt maintenance retains the latest 8 local no-effect snapshots. Relabel and delete controls mutate only this isolated test lane state.

Receipt diff detail compares stable saved and current no-effect receipt fields. Changed rows are audit hints only and do not become production evidence.

Saved review context drift compares selected saved receipt focus against current comparison, trace, blocker, handoff, and authority state without creating production evidence.

The receipt export preview is a local JSON artifact for the isolated test UI lane only. It is explicitly marked not production evidence.

Export validation checks local-only schema, watermark, zero authority fields, selected snapshot, and diff filter binding before a local JSON preview is considered ready.

QA handoff link and manifest are local no-effect review aids. They do not create production evidence, host writes, or main or edge GUI mutations.

QA replay strip summarizes requested URL state, applied local UI state, and zero-authority boundaries for the isolated test lane.

Release acceptance rows combine local UI proof, migration, engine, accessibility, and production evidence gates without granting production promotion authority.

Assistive evidence rows track keyboard, screen-reader, and live-region proof needed before any guarded Panel migration.

Component toggles update only the isolated test-lane plan and receipt preview.

Console commands are limited to the test-lane allowlist. Blocked commands do not change mode, prefix, components, installer state, or production claims.

Command palette rows can run allowlisted panel commands or jump to local UI review surfaces. They do not launch a shell, write to the host, or mutate the main or edge GUI.

Operator focus dock buttons mirror selected local review context and jump only within this isolated test UI lane.
