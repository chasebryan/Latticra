Local Operator Surface

Console, Panel, and Nadia

The workbench lane makes Latticra locally visible without granting broad authority: Panel guides the install path, LC reports console metadata, and Nadia records offline AI planning contracts.

Workbench Posture

Visible locally, guarded by default.

Panel, LC, and Nadia are designed as local operator surfaces. Their current role is configuration, dry-run planning, reports, receipts, context metadata, and contract evidence, not root installation, host automation, inference, tool execution, or network behavior.

01

Panel

Guided local workbench for dry-run plans, component choices, delivery controls, and evidence review.

02

LC

Panel-aware operator console with metadata-only commands and no external host process launch.

03

Seal receipts

Receipt requests and capability labels bind future authority claims back to evidence records.

04

Nadia

Offline AI foundation for context packs, prompt plans, safety metadata, and blocked evaluation contracts.

05

Local evidence

User-local verification records what exists without claiming root, network, runtime, or production readiness.

Panel

The first-run surface is a guided workbench.

Latticra Panel opens as a local GUI workbench with guided defaults, visible authority boundaries, plan/evidence review, an embedded console, and dry-run-first local installation controls.

Three Surfaces

Each lane has a different job.

The workbench is easier to read when Panel, LC, and Nadia stay separate.

Panel

Guided local install and review

Runs from source or user-local install paths, presents plans and receipts, and keeps guarded local-prefix writes behind explicit modes.

Metadata-only operator console

Nadia Boundary

Stage-38 is still contract-only.

Nadia now records a prompt-evaluation result release receipt review disposition release contract path, but disposition recording, disposition decisions, disposition findings, review recording, review decisions, review findings, receipt recording, receipt signing, receipt publication, release recording, model output, runtime invocation, prompt evaluation, token generation, inference, and dialogue generation remain blocked.

Present

Identity, local config, context packs, runtime profile metadata, prompt plans, safety contracts, and prompt-evaluation result release receipt review disposition release contract metadata.

Denied

Model loading, prompt evaluation, token generation, inference, result release, tool execution, source mutation, training, and network use.

Next boundary
