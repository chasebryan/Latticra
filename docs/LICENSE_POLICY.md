# Latticra License Policy

Status: initial license policy
Scope: Apache-2.0 usage, documentation/code scope, branding, contributions, and future artifacts.

## Purpose

Latticra uses Apache License 2.0 as the project license.

This policy explains how that license should be understood inside the repository.

## License

The repository license is:

```text
Apache-2.0
```

The canonical repository license file is:

```text
LICENSE
```

## Scope

Unless a file explicitly says otherwise, Apache-2.0 applies to:

- source code;
- documentation;
- configuration files;
- examples;
- tests;
- scripts;
- fixtures.

## Contributions

Contributions submitted to Latticra are expected to be contributed under Apache-2.0 unless the contribution is clearly marked otherwise and accepted intentionally.

Do not add code, docs, assets, or generated material with incompatible licensing unless the licensing decision is documented.

## Branding and trademarks

The Apache-2.0 license does not grant trademark or branding rights.

Project names, logos, marks, and Bryforge/Latticra branding should be treated separately from code and documentation licensing.

## Third-party material

Third-party material must include source, license, and compatibility notes before being added.

Required fields:

```text
name:
source:
license:
compatible with Apache-2.0: yes|no|unknown
purpose:
notes:
```

## Generated artifacts

Generated artifacts may need additional notices depending on source inputs, build process, and bundled dependencies.

No release artifact should be published until its licensing and notice requirements are reviewed.

## NOTICE file

A future `NOTICE` file may be added when Latticra has third-party notices, attribution requirements, or distribution notes to preserve.

## Future dual licensing

No dual-license model is currently declared.

If dual licensing is considered later, it must be documented before being applied to code or releases.

## Non-claims

This policy is project guidance and not legal advice.

For commercial licensing strategy, patent strategy, trademark strategy, or formal release review, obtain qualified legal review.
