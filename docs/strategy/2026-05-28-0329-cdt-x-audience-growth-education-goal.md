## Goal

Grow @Latticra by teaching what Latticra is, why the work matters, and how evidence-bound systems engineering can be understood by both technical and general audiences.

This is a growth target, not a forecast:

```text
30-day target: first 100 relevant followers
90-day target: first 500 relevant followers
quality target: attract systems, Linux, security, cryptography, open-source, AI-tooling, and technical-builder audiences
```

The account should become known for:

```text
clear explanations
beautiful diagrams and visual language
careful claims
practical systems thinking
open-source research discipline
public learning without hype
```

## Audience Promise

Every educational post should help the reader understand one of these ideas:

```text
what Latticra is
what problem Latticra is studying
why boundaries matter
why authority should be visible
why evidence should come before claims
how Linux-native secure substrates might be evaluated
how cryptographic infrastructure can be discussed without hype
```

The account should be professional enough for researchers and maintainers, but plain enough that a curious non-specialist can still follow the arc.

## Content Standard

Each post should pass this test before publication:

```text
one idea
plain first sentence
specific Latticra connection
no unsupported security claim
no unexplained jargon unless the post teaches it
calm ending
```

Visual standard:

```text
clean
spacious
legible on mobile
high contrast
one concept per image
few words
official Latticra emblem from docs/assets/latticra-official-emblem.png
no decorative clutter
```

## Growth Loop

Daily loop:

```text
publish or prepare 1 educational post most days
keep outbound public actions about 5 hours apart
reply thoughtfully only when a relevant technical conversation is worth entering
save 1 strong external post for possible quote or repost
skip missed windows instead of compressing the cadence
```

Weekly loop:

```text
publish 1 short educational thread
create or prepare 1 visual explainer
review follower growth and best-performing topics
refresh the draft queue
keep curated reposts sparse and high-signal
```

Monthly loop:

```text
review which content lanes gained aligned followers
turn the strongest post into a pinned orientation thread
update the bio if the public story has sharpened
```

## Reply Principles

Reply to people when the account can add clarity, not noise.

Useful reply shapes:

```text
define a term
share a boundary
name a limitation
point to an evidence artifact
ask a precise technical question
thank someone for a useful framing
```

Avoid:

```text
argument for visibility
generic agreement
performative certainty
founder-only inside language
claims that require evidence not yet public
```
