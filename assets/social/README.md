# Latticra Social Assets

Status: active social asset workspace
Official emblem: `../../docs/assets/latticra-official-emblem.png`

## Quality Bar

Social cards must be:

```text
beautiful before numerous
aligned to a visible grid
legible at mobile size
quietly premium
evidence-bound
clear about one idea
branded with the official blue lattice emblem
or the official wordmark when the card needs a premium brand-led opening
the word Latticra no more than once per card
the official emblem plus exactly one written Latticra for publishable brand-led cards
```

Avoid:

```text
template-like flowcharts
busy boxes
misaligned captions
cramped pills
generic placeholder marks
repeating Latticra in both wordmark and footer/handle
placing the official banner image as a background instead of recreating the design language across the whole card
posting a card merely because it exists
```

## Review Rule

Do not attach a social card to @Latticra unless the exact card receives visual approval.

When using `latticra-official-wordmark.jpeg`, do not add `@Latticra`, a second wordmark, or another written instance of the word Latticra.

The official wordmark banner can be used as style inspiration. It should not be pasted into a card as the card background.
